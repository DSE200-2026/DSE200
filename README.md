## Before you start

1. **Save your own copy.** In Colab: *File → Save a copy in Drive*. Otherwise your work is lost when you close the tab.
2. **Run the SETUP cell first.** It downloads the data (`temperatures.csv` on Day 1, the MovieLens files on Day 2, `customers.csv` and the feature engineering files on Day 3) from this repository for you.
3. **Lost?** *Runtime → Run all*. Every section rebuilds its own data, so any section works from cold.
